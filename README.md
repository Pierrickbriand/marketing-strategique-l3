# Marketing stratégique · Licence 3 · UCO Nantes

Cours interactif des TD de marketing stratégique, année 2026-2027, animé par Pierrick Briand.

Le cours est en ligne : https://pierrickbriand.github.io/marketing-strategique-l3/

Les réponses des étudiants restent dans leur navigateur. Chaque groupe enregistre son travail en fichier .json à la fin de chaque séance.

Ce dépôt contient seulement l'édition étudiante, sans corrigés. Elle est fabriquée avec le kit « cours interactif » (version 24).
